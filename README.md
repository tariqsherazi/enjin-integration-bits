Enjin Integration Bits

A blockchain integration platform built around the Enjin ecosystem — enabling NFT minting, wallet linking, and token-gated access for web applications.

Structure

This is a multi-part project:

backend/ — API layer handling Enjin blockchain interactions (minting, wallet verification, token queries)
frontend/ — Customer-facing app for connecting wallets and viewing/minting NFTs
frontend-admin/ — Admin dashboard for managing NFT collections, monitoring mint activity, and user wallet data
Tech Stack
Backend: Node.js
Frontend: JavaScript
Blockchain: Enjin platform integration
Features
Wallet connection and verification
NFT minting flow
Token-gated content/feature access
Admin visibility into blockchain activity
Status

This project was built as an exploration into blockchain/NFT integration patterns for web apps.
